# SyncPro balanced hard-F1 offline case viewer

Download `syncpro_balanced_hard_f1_offline_viewer_context5s.zip`, extract it,
and open `index.html` in a browser. The package is fully offline and contains
1,349 numbered benchmark cases with 72,412 unique JPEG frames. Each selected
GT, SPEAK, or preceding THINK anchor includes up to five seconds of neighboring
frames on each side at one frame per second.

The archive is stored with Git LFS. If a browser download is interrupted or
truncated, install Git LFS, clone this branch, and run:

```bash
git lfs pull --include="artifacts/syncpro_balanced_hard_f1_offline_viewer_context5s.zip"
```

- Archive size: 1,366,601,711 bytes
- SHA-256: `5b8ea5e437a9f3da6202f8f91a897a6d64be2d92bfa65a2c56b041f46e61bc54`
- Full videos are intentionally excluded and can be retrieved later using the
  benchmark name and case identifier displayed by the viewer.
